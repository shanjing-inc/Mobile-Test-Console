# 优化 Suite 测试结果展示

## 目标

让 `executionKind: suite` 的单元测试结果使用 Suite 专用信息架构，清晰展示源文件、测试点数量、执行状态、耗时与失败详情。

## 背景

- 当前结果列表统一显示页面跳转、设备、接口、截图和动作摘要。
- Suite 结果没有页面跳转与设备语义，当前界面会出现 `? → ?` 和“未记录设备”。
- SaaS 小程序会把 Vitest assertion 按 `ancestorTitles` 聚合，并通过 Result Bundle metadata 传递 `executionKind: suite` 和结构化 assertions。

## 需求

- Suite 列表展示可读 `caseId`、测试文件路径、测试点总数、通过数、失败数、跳过数与总耗时。
- Suite 列表隐藏页面跳转、设备、接口、截图和页面动作摘要。
- Suite 详情按测试点展示状态、名称和耗时。
- Suite 失败详情展示错误摘要，并保留错误复制、单套件重试与失败批量重试能力。
- 页面回放和场景结果保持现有展示。
- 纯 Suite 运行的工具栏同时展示套件数和测试点总数。

## 验收标准

- [x] Suite 结果列表不出现 `? → ?` 与“未记录设备”。
- [x] Suite 结果列表展示测试文件和测试点统计。
- [x] 展开 Suite 可以查看每个测试点的状态、名称和耗时。
- [x] Suite 失败时展示失败说明，并保留重试与复制错误入口。
- [x] 页面回放和场景结果相关回归测试通过。
- [x] 桌面和 390px 视口均无文本重叠或横向溢出。

## 范围外

- 修改项目侧 Vitest Result Bundle 生成逻辑。
- 改变 Result Bundle schema 版本。
- 改变重试命令的项目侧筛选能力。
