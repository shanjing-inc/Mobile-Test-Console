# 执行计划

1. 扩展共享契约：入口来源、命令预览请求/响应、脱敏命令项。
2. 在配置层增加带来源的公开入口投影，统一 `/api/snapshot`、项目详情和入口编辑器输出，并覆盖历史配置回退测试。
3. 增加命令预览服务/API：校验入口、目标和参数，复用页面选择展开与 `resolveTargetCommand()`，替换 env 值并返回结构化结果；保留自定义 Runner 接管型入口。
4. 导出 `ProjectTestEntryWizard` 供执行页复用，并移除项目概览中的添加入口、局部状态和重复弹窗挂载。
5. 在小程序执行页入口控件旁接入“添加自定义命令”；保存后刷新快照、选中新入口并恢复匹配目标。
6. 扩展右侧说明区域：显示来源与用途；单目标完整命令；多目标摘要和当前页详情弹窗；加载、空目标、错误与复制状态完整。
7. 将命令预览有效性加入启动按钮条件，处理快速切换入口/目标/参数时的过期响应。
8. 补充回归测试：
   - 主配置/sidecar 来源投影与兼容回退；
   - 预览解析、参数默认值、目标差异、未知/不支持目标、无命令和 env 脱敏；
   - 执行页预制/自定义标识、添加入口、保存后自动选择；
   - 单目标完整显示、多目标详情、过期响应和启动禁用；
   - 项目概览不再展示添加测试命令入口；
   - `390x844` 无横向溢出。
9. 在 SaaS 小程序 `mobile-test.config.cjs` 增加“员工取件码排序验证”预制入口，映射已有 `pnpm test:e2e:pickup-code-sort` 脚本，并补充配置回归测试和项目规范。
10. 将五步添加向导收敛为单页快速表单：名称、单行命令、可选说明和默认收起的高级设置。
11. 增加安全命令 tokenizer 与自动 ID/默认目标物化逻辑；支持引号参数并拒绝复合 shell 语法。
12. 将 preview/apply 串联到单个“保存命令”动作，保留计划过期、原子写入、备份、脱敏与保存后自动选择。
13. 重组高级设置：目标、类型、业务分类、cwd、env、参数、页面重试、JSON 与 AI 说明按需展开。
14. 更新回归测试：
   - 快速表单首屏字段和默认值；
   - 自动 ID 冲突后缀与默认全部目标；
   - 普通参数、单/双引号解析和复合 shell 拒绝；
   - 保存失败保留输入、成功自动选择；
   - 高级设置与页面重试确认；
   - 桌面及 `390x844` 布局。
15. 解耦命令预览范围与实际运行选择：空选择按入口支持目标预览，单目标入口首次自动勾选，启动成功保留目标选择；覆盖入口切换、空选择、多目标、显式选择和启动后持久性。
16. 执行 `pnpm exec tsc --noEmit`、`pnpm exec eslint src tests`、`pnpm exec vitest run`、`pnpm build`、Schema/发布包检查和 `git diff --check`，再进行桌面与 390px 浏览器验证。

## 风险与回滚点

- `src/server/config.ts` 的公开入口投影影响多个 API，先完成来源单元测试。
- 命令预览必须与实际启动共用解析函数，避免前后端各自解释模板。
- `src/web/ProjectCatalogWorkspace.tsx` 当前包含向导实现，提取时保持现有项目概览测试通过。
- 单行命令属于输入便利层，持久化和执行继续使用结构化 executable/args；检查中重点验证两种表示不会漂移。
- 当前工作区包含前一任务的已暂存变更，实施阶段只追加本任务改动并保留用户现有状态。
