# Mobile Test Console 测试套件说明与页面列表

## Goal

让 Mobile Test Console 的测试参数选项支持内容说明，并在 Fanli 的 Lynx 页面套件选择器中展示每个套件的覆盖范围和用例数量；同时提供完整页面列表、参数编辑和单页测试入口，帮助使用者在启动前明确测试内容并准备页面参数。

## What I already know

- Fanli 在 `qa/mobile-test.config.cjs` 中声明 `Lynx 页面套件`，包含 `Smoke`、`P0`、`P1`、`P2`、`全部页面`、`全部业务流程` 六个选项。
- Mobile Test Console 的通用配置协议当前只支持 option 的 `value` 和 `label`。
- `Smoke` 覆盖 6 个核心页面快速检查，`P0/P1/P2` 各覆盖 5 个业务链，`全部业务流程` 合计覆盖 15 个业务链。
- `全部页面` 根据用户可见 Lynx 页面清单动态生成，当前覆盖 78 个基础启动与渲染用例。

## Requirements

- 通用 select option 协议增加可选 `description` 字段，旧项目配置继续有效。
- 配置解析保留 option 说明并通过快照 API 提供给浏览器。
- 测试参数选择器在下方展示当前选项说明，切换选项时同步更新。
- Fanli 六个 Lynx 套件选项都提供简洁、具体的覆盖说明。
- 文档记录 option 说明字段及 Lynx 套件说明维护要求。
- 将控制台“页面参数”导航改为“页面列表”，目录展示 `all-pages` 套件中的全部用户页面。
- 页面列表支持按页面名或 bundle 搜索，并能筛选需要参数的页面。
- 读取路由参数或存在动态参数读取点的页面显示特殊参数标识；无参页面显示可直接测试。
- 选中页面后展示参数契约，参数支持真机录制、历史画像补全和手动编辑。
- 用户选择设备后可保存当前参数并直接启动单页面测试。

## Acceptance Criteria

- [x] 选择 `Smoke/P0/P1/P2/全部页面/全部业务流程` 时，界面展示对应覆盖内容。
- [x] 切换套件后说明与当前值一致。
- [x] 缺少 `description` 的现有选项仍可正常解析和展示。
- [x] 配置测试验证说明字段被保留，旧配置默认获得空说明。
- [x] Mobile Test Console 完整质量检查通过。
- [x] 页面列表展示全部用户可见 Lynx 页面，并能搜索和筛选参数页。
- [x] 需要参数、动态参数和无参页面具有清晰状态标识。
- [x] 选中任意页面后能使用当前参数启动单页面测试。

## Technical Approach

在 `SelectParameterOption` 和 Zod 配置 schema 中增加可选说明字段，由项目配置负责提供业务文字。浏览器根据当前参数值查找对应 option，并在原有选择器下渲染说明。页面目录由 Fanli provider 基于 `all-pages` 套件生成，参数契约、录制画像、手动值和单页测试继续使用现有页面参数协议。

## Out of Scope

- 自动从 QA 用例清单生成自然语言说明。
- 展开显示套件内每个用例的完整明细。
- 修改各套件实际执行内容或优先级。

## Definition of Done

- 两个仓库的协议、配置、界面、测试和集成规范保持一致。
- Mobile Test Console 的 lint、测试、类型检查与构建通过。
- 本地浏览器确认桌面与窄屏下说明文字清晰且无布局溢出。
