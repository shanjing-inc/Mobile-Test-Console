# 归并复测运行记录

## Goal

复测保持独立执行 attempt 和产物，但运行监控沿用原记录展示最新 attempt，避免同一设备出现重复运行行。

## Requirements

- 复测启动时原任务自动标记长期保留，旧产物继续入库。
- 运行列表按重试链只展示最新任务；最新任务完成后状态、耗时和详情均来自最新 attempt。
- 旧任务仍可通过历史或存储服务访问，删除最新展示行不删除旧入库产物。
- 页面单模块复测继续只执行目标页面。

## Acceptance Criteria

- [x] 复测后运行监控中同一来源链只显示一行。
- [x] 原任务 `retained=true`，最新任务承载当前状态和结果。
- [x] 运行列表归并、聚焦、删除和保留按钮有回归测试。
- [x] 全量测试、类型检查、lint 和构建通过。
