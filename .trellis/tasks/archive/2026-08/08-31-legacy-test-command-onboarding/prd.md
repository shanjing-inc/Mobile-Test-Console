# 旧测试命令可视化接入

## Goal

让已经拥有测试体系的小程序项目按照 MTC 契约手动添加测试命令，通过分步引导完成测试入口、运行目标、参数和重试兼容配置，并在确认后安全写入项目。

## Background

- 项目已有测试命令、测试框架、业务脚本和结果产物继续由项目维护；MTC 负责入口声明、运行调度、状态、重试和结果展示。
- 不同项目的测试方案和命令语义差异较大，命令来源统一由用户按照 MTC 规则手动填写。
- `mobile-test.config.cjs` 支持动态表达式、条件展开和注释，整文件 JSON 序列化会破坏项目逻辑。
- 项目接入已有 preview/apply、计划过期校验和冲突检测流程，可作为写入边界。

## Requirements

### R1. 添加命令引导

- 小程序项目概览提供“添加测试命令”入口。
- MTC 只接收用户明确填写的命令，不扫描、猜测或推荐项目命令。
- 引导按测试信息、运行目标、命令、参数与重试、确认五个步骤组织。
- 每个字段展示用途、格式、示例和对应的 MTC 规则，避免要求用户直接编辑完整配置对象。
- 支持返回前一步修改，动态保留尚未提交的表单内容。

### R2. 结构化测试入口

- 支持填写测试 ID、名称、说明和 `general | page | flow` 类型。
- 运行目标从项目已声明的 `testing.targets` 中选择，小程序入口至少选择一个 `targetKey`。
- 命令按 `executable`、参数列表、工作目录和环境变量键值对填写，不接收未经解析的 shell 命令串。
- 参数支持现有 select、page-selection 和 account-profile 类型；首版提供常用模板并允许调整。
- 页面测试明确展示 `MTC_RETRY_TARGET_PAGES`、`MTC_RETRY_CASE_IDS` 和 `MTC_RETRY_CASE_RUN_IDS` 接入说明。

### R3. 独立入口文件

- 可视化编辑器将测试入口保存到配置文件同目录的 `mobile-test.entries.json`。
- MTC 配置加载器自动读取该文件，并与 `mobile-test.config.cjs` 中已有 `tests` 合并。
- 两个来源出现相同测试 ID 时配置加载失败并给出来源诊断。
- 写入独立入口文件时保持 `mobile-test.config.cjs` 内容原样。

### R4. 预览与应用

- 表单提交先生成预览计划，展示结构化配置、命令展开示例、目标文件和校验结果。
- 预览只解析命令，不执行测试。
- 用户确认后写入；应用时重新计算计划摘要，文件发生变化则返回过期错误。
- 写入使用临时文件与原子替换，现有入口文件保留可恢复备份。

### R5. 校验与兼容

- 服务端统一校验测试 ID、目标引用、命令字段、模板变量、参数定义、路径边界和重复项。
- 工作目录必须位于项目根目录内，符号链接解析后仍需满足边界。
- 现有只在 `mobile-test.config.cjs` 声明 `tests` 的项目继续加载和执行。
- 保存成功后刷新项目检查结果，新入口出现在测试入口清单和运行页面。

### R6. AI 操作引导

- 引导页提供“复制 AI 接入说明”，内容包含 MTC 字段契约、当前项目运行目标、重试环境变量和脱敏后的表单草稿。
- AI 引导用于帮助用户整理已有命令和填写表单，首版由用户确认并提交最终配置。

## Acceptance Criteria

- [ ] 小程序项目概览能打开“添加测试命令”五步引导页。
- [ ] 用户可以创建一个页面测试入口，选择运行目标，逐项填写 executable、args、cwd、env 和页面参数。
- [ ] 页面测试引导明确展示重试环境变量及旧脚本适配示例。
- [ ] 预览展示目标文件、完整 JSON、命令展开结果和所有校验问题，预览过程不执行命令。
- [ ] 用户确认后只创建或更新 `mobile-test.entries.json`，主配置字节内容保持一致。
- [ ] 预览后入口文件被外部修改时，应用返回计划过期错误且保留外部修改。
- [ ] 重复测试 ID、未知目标、未知模板变量、项目外 cwd 和无命令入口均被服务端拒绝。
- [ ] 保存后项目测试清单和运行页面能读取新入口，原有主配置测试继续可用。
- [ ] “复制 AI 接入说明”包含当前 MTC 契约和表单草稿，不包含环境变量敏感值。
- [ ] 服务端、配置加载和 Web 具备新增入口、预览、过期保护、边界校验、兼容加载和交互回归测试。

## Out of Scope

- 项目命令发现、扫描、猜测和推荐能力。
- 自动判断自定义测试框架的内部语义。
- 首版编辑或删除主配置中的测试入口。
- 首版内置 Codex 隔离任务与自动补丁应用。
- 预览阶段或保存后自动执行测试命令。
- 原生实现微信、支付宝等小程序开发者工具连接器。
