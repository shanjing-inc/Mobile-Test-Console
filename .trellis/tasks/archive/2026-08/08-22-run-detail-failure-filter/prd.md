# 运行详情失败筛选

## Goal

在运行详情的概览页快速定位失败用例。用户点击失败统计后，下面的测试条目列表只展示失败测试条目，方便直接查看报错页面。

## Confirmed Facts

- 运行详情概览由 `src/web/App.tsx` 的 `OverviewResult` 渲染。
- 页面已有通过、失败、截图、接口统计，以及测试条目列表。
- 失败用例已有独立的 `run.status === "failed"` 状态和批量重试入口。

## Requirements

- 失败统计项支持点击，点击后列表只展示失败测试条目。
- 列表提供明确的当前失败筛选状态，并支持恢复查看全部测试条目。
- 筛选只影响当前概览列表，不改变服务端结果、统计数字、重试逻辑和详情展开状态契约。
- 空筛选结果需要显示清晰的空状态。
- 交互具备键盘可操作性和可识别的选中状态。

## Acceptance Criteria

- [x] 在包含失败用例的运行详情中点击“失败”统计后，列表只渲染失败条目，列表计数同步反映当前视图。
- [x] 用户可以从失败筛选视图恢复“全部”条目；恢复后通过和失败条目均可见。
- [x] 失败筛选下批量重试仅提交当前失败条目的 `caseRunId`，没有失败条目时批量重试按钮隐藏或不可用。
- [x] 没有匹配条目时展示空状态，页面布局无水平溢出。
- [x] 现有截图显示/隐藏、单条展开、单条重试和诊断详情行为保持可用。
