# 修复页面列表滚动并显示总数

## Goal

稳定 Mobile Test Console 页面列表的独立滚动行为，并在“全部”筛选按钮中直接展示页面目录总数。

## What I already know

- 页面目录当前包含 78 个用户可见 Lynx 页面。
- 页面列表容器高度为 760px，内容高度约为 5226px。
- 列表滚到底后继续滚动会把滚动传给页面，实测页面从 `scrollY=0` 移动到 `435`，形成内容跳动。
- 页面轮询刷新期间列表 `scrollTop` 保持稳定，当前问题来自滚动边界传递。

## Requirements

- 页面列表滚动保持在列表容器内，滚动到顶部或底部后不带动外层页面。
- 页面列表预留稳定的滚动条空间，避免滚动条状态变化引起行内容横向位移。
- “全部”筛选按钮显示完整页面目录总数，格式为 `全部 78`。
- “需参数”继续显示参数页面总数。

## Acceptance Criteria

- [x] 列表中间滚动时只有列表 `scrollTop` 变化。
- [x] 列表到达底部后继续向下滚动，页面 `scrollY` 保持不变。
- [x] 页面轮询刷新后列表 `scrollTop` 保持不变。
- [x] “全部”显示 78，“需参数”显示当前参数页面数量。
- [x] 桌面与窄屏布局无水平溢出。
- [x] Mobile Test Console lint、测试、类型检查和构建通过。

## Technical Approach

- 在页面列表滚动容器上使用 `overscroll-behavior: contain` 隔离滚动链。
- 使用 `scrollbar-gutter: stable` 固定滚动条占位。
- 复用页面目录总数生成筛选按钮文字。

## Out of Scope

- 虚拟列表改造。
- 修改页面目录生成规则或参数分类规则。
- 改变页面选择和单页测试流程。

## Definition of Done

- 自动化质量检查通过。
- 浏览器实际滚动测量验证列表边界稳定。
- 任务改动与用户现有工作区改动保持隔离。
