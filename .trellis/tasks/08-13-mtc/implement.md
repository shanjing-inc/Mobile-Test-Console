# 实施记录

1. 页面范围改为 MTC 用户显式选择，创建任务时把预设展开为冻结页面 ID。
2. 页面选择器支持搜索筛选、全选/取消当前、清空和逐项选择，并抽象为通用 `PageSelectionItem`。
3. 重试请求保存来源 case、页面和路由参数，通过 Runner metadata 与标准环境变量下发。
4. 运行列表隐藏独立重试行，来源测试组在活动重试期间显示状态并锁定变更操作。
5. 来源结果按时间累计全部终态重试，只用通过结果原位替换对应 item；失败或不可用结果保留原 item。
6. 删除来源任务时遍历完整重试链；活动后代阻止删除，全部终态后一次清理记录与产物。
7. Fanli Provider 和命令适配 MTC 通用范围，项目配置只提供页面数据与执行映射。

## 回归场景

- 原始 A/B 均失败，重试 A 通过，再重试 B 失败：A 显示新通过结果，B 保留原失败结果。
- 原始 A/B 均失败，分别重试 A/B 通过：最终 A/B 均显示通过结果。
- 活动重试期间点击删除：前端禁用，服务端返回 `TASK_ACTIVE`。
- 重试结束后删除来源组：一次删除完整重试链。
