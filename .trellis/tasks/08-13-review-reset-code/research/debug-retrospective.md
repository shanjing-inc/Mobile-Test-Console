# 重制代码审核复盘

## 1. 根因分类

- B 跨层契约：复测范围、attempt、来源链、结果匹配和页面目录分别由 API、任务管理器、结果服务与前端消费，部分约束缺少单一权威实现。
- D 测试覆盖缺口：既有测试覆盖单次复测和唯一 `caseId`，遗漏兄弟复测、同名跨页面用例、嵌套复测刷新和运行列表上限。
- E 隐式假设：空字符串被默认值覆盖、页面 ID 被假定为简单标识符、公开最近任务列表被当作完整任务集合。

## 2. 多次修复失效原因

1. 局部补传环境变量解决了执行命令范围，复测链的 attempt、状态投影和结果匹配仍位于其他层。
2. 单用例测试数据使用唯一 `caseId`，回退匹配在真实同名跨页面数据中存在歧义。
3. 前端禁用操作提供了即时反馈，服务端保留接口仍可被直接调用。
4. 最近 100 条任务适合界面展示，调度、链遍历和结果累计需要完整持久化集合。

## 4. 系统性扩展

- 任何展示用分页或截断集合都只能参与投影，调度、锁、清理和关系遍历使用完整状态源。
- 复合业务标识优先使用精确 ID；兼容回退键需要唯一性证明。
- 用户显式空值需要与参数缺省分开处理。
- 跨层状态机测试需要覆盖兄弟分支、多层后代、失败路径和数据规模边界。
