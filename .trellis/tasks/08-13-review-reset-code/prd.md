# 重新审核重制代码并提交

## Goal

对当前工作区中已重制的页面选择与复测链路进行一次从契约到界面的完整审核，修复确认存在的问题，通过项目质量门禁后提交全部相关改动，提交信息使用中文。

## Confirmed Facts

- 当前改动覆盖共享契约、Runner、服务端任务管理与结果合并、Web 界面、Lynx 示例、文档、测试和 Trellis 规范。
- 页面测试范围改为用户显式选择；优先级和标签继续用于筛选、展示、报告与录屏策略。
- 单项复测通过 `retryOf`、Runner metadata、模板变量和环境变量向项目适配器下发页面与用例范围。
- 运行列表只展示来源测试组；来源任务结果按创建时间累计终态重试中通过的用例结果。
- 删除来源任务需要清理完整重试链；活动重试期间需锁定删除、保留和重复重试操作。
- 工作区包含用户已有的 Trellis 任务、归档、规范和开发日志改动；本次提交需保留这些现有改动并确认提交边界。

## Requirements

- 按跨层数据流审核页面选择、任务创建、定向复测、结果合并、运行列表投影和删除清理逻辑。
- 核对共享类型、API 校验、持久化结构、Runner metadata、命令模板、环境变量和 Result Bundle 字段的一致性。
- 针对同一问题曾多次误修的风险，验证兄弟重试、多层重试、部分通过、失败、取消、结果缺失、活动重试和完整链删除等边界。
- 审核页面选择的默认值、搜索、筛选、全选当前、反向取消、清空、显式页面 ID 冻结和空选择校验。
- 审核 Web 操作状态与服务端约束保持一致，并检查桌面和窄屏布局回归。
- 每条审核发现都需由代码路径或可复现测试验证；修复后增加或加强防回归测试。
- 运行 lint、类型检查、全量测试、Schema 检查、开源检查、构建和包内容检查。
- 提交信息使用中文；提交前核对暂存文件，避免遗漏本次相关文件或混入无关文件。

## Acceptance Criteria

- [x] 页面选择与复测链路的跨层契约保持一致，定向复测只执行并输出目标页面或用例。
- [x] 来源结果只吸收终态重试中通过的匹配项，其他原结果稳定保留；多次与多层重试累计结果正确。
- [x] 活动重试锁定相关操作，删除来源任务可清理完整终态重试链及其产物。
- [x] 页面选择交互与任务保存范围一致，空选择和未知选择得到明确处理。
- [x] 审核发现的问题已修复，并有对应回归测试或现有测试提供充分覆盖。
- [x] `pnpm check` 通过；必要的针对性测试独立通过。
- [ ] 最终差异与暂存清单经复核，提交使用中文提交信息且提交成功。

## Out of Scope

- 引入与当前页面选择或复测链路无关的新功能。
- 重构未受本次改动影响的模块。
- 修改外部 Fanli 仓库；本仓库只审核其通用契约、示例和文档。
